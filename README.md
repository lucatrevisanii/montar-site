# Montar o meu site

Um roteiro pra montar um site com o Claude, do seu gosto até um protótipo testado.

Você traz o projeto, os sites de que gosta e o material real que já tem. O Claude conduz, pergunta, pesquisa e constrói, e para no fim de cada etapa pra você aprovar.

## Como começar

1. Copie este repositório pra sua conta com o botão **Use this template**, ou baixe a pasta.
2. Instale o Claude Code no seu computador: https://code.claude.com/docs/en/quickstart
   - Nunca usou terminal? Comece por aqui: https://code.claude.com/docs/en/terminal-guide
   - Prefere um aplicativo? https://code.claude.com/docs/en/desktop
3. Abra esta pasta no Claude Code.
4. Escreva `começa`.

Pra adiantar, preencha `insumos/respostas.md` antes do passo 4 e ponha fotos, logo e textos em `insumos/material/`. Se não preencher, o Claude pergunta.

## O que vai acontecer

| Parte | O que sai dela |
| --- | --- |
| 0. Insumos | O que o Claude entendeu do projeto e o que ainda falta |
| 1. Pesquisa curta | O que os sites da sua categoria fazem, com contagem |
| 2. Entrevista de gosto | Seu perfil de gosto em uma tela, em `processo/perfil.md` |
| 3. Direção | `DESIGN.md`: logo, cor, letra, imagem, movimento, voz |
| 4. Protótipo | A página inicial em `site/`, comparada com os sites de que você gosta |
| 5. Teste de 5 segundos | O placar: quem bate o olho entende o que é e pra quem? |

O protótipo ainda não é o site no ar. No fim, o Claude diz o que falta pra publicar onde você escolher.

## O que fica com você

- Toda decisão de gosto. O Claude mostra exemplos reais numerados e você responde pelos números.
- Publicar, comprar domínio, criar conta, gastar dinheiro: só com o seu ok.
- Nada é inventado. Número, cliente e depoimento só entram se você deu.

## Pastas

- `insumos/respostas.md`: suas respostas sobre o projeto.
- `insumos/material/`: textos, fotos e logo.
- `insumos/referencias/`: capturas de tela de sites, se o Claude pedir.
- `processo/`: o perfil de gosto e o gabarito do teste.
- `site/`: o protótipo.
- `CLAUDE.md`: as instruções que o Claude segue aqui. Pode ler e mudar.
